# Alcance de la primera versión

### Incluido
- Ingestión de mediciones.
- Persistencia cloud.
- Motor de riesgo determinista.
- Alertas automáticas para ALTO/CRITICO.
- API HTTP.
- Dashboard estático inicial.
- Pruebas unitarias del motor de riesgo.

### Siguiente iteración
- Conectar fuentes oficiales de precipitación y caudal.
- Agregar geodatos y mapa de riesgo.
- Configurar umbrales por cuenca.
- Añadir autenticación de operadores.
- Añadir métricas y alarmas de CloudWatch.
- Reemplazar el motor por un modelo predictivo cuando exista un dataset validado.
